# Fontes do Kriart

Adione nesta pasta as fontes utilizadas no projeto:

## Fontes Recomendadas

### Para o Polaroid (composição de imagem):
- **Poppins-Regular.ttf** — Texto do polaroid
- **Poppins-Bold.ttf** — Frase em destaque
- **Poppins-Italic.ttf** — Nome do participante

### Download:
Google Fonts: https://fonts.google.com/specimen/Poppins

## Como usar
As fontes são carregadas automaticamente pelo `PolaroidService`.
Se não encontradas, o sistema usa a fonte padrão do Pillow como fallback.

## Instalação no Windows
Baixe o ZIP, extraia e instale os arquivos .ttf clicando com botão direito → Instalar.
O Pillow encontrará a fonte pelo nome `poppins` automaticamente.
